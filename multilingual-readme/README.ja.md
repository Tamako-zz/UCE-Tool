# UCE Tool

[简体中文](README.zh-CN.md) | [English](README.en.md) | [Deutsch](README.de.md) | **日本語** | [Français](README.fr.md)

UCE Tool は USB-C Explorer 用のデスクトップアプリです。リアルタイム測定、E-Marker の読み取り、充電プロトコル検出、デバイスのファームウェア更新、テーマカラーの設定に対応しています。

Windows 64 ビット、Apple Silicon および Intel 搭載 Mac に対応し、中国語・英語・ドイツ語・日本語・フランス語で使用できます。

<a id="download"></a>
## ダウンロードとインストール

[リリースページ](https://github.com/Tamako-zz/UCE-Tool/releases/latest)の **Assets** から、お使いの環境に合ったファイルを選択してください。

| ファイル | 対象 | アプリ |
| --- | --- | --- |
| `UCE-Windows-x64.zip` | Windows 64 ビット、Intel / AMD | `UCE.exe` |
| `UCE-mac-arm64.dmg` | Apple Silicon（M シリーズ）搭載 Mac | `UCE.app` |
| `UCE-mac-x86_64.dmg` | Intel 搭載 Mac | `UCE.app` |

Mac のプロセッサは「Apple メニュー → この Mac について」で確認できます。

**Windows：** ZIP を完全に展開し、展開先の `UCE.exe` を起動します。

**macOS：** 対応する DMG を開き、`UCE.app` を **Applications** にドラッグします。ディスクイメージを取り出し、「アプリケーション」から UCE を開きます。初回起動時にブロックされた場合は、入手元を確認して「システム設定 → プライバシーとセキュリティ」で許可してください。

<a id="connect"></a>
## デバイスの接続

USB-C Explorer、データ通信可能な USB ケーブル、ハードウェアに対応した APP ファームウェアが必要です。テーマやプロトコル検出にも対応するファームウェアが必要です。

1. UCE Tool を起動し、デバイスのデータ通信端子をパソコンに接続します。
2. 自動検索・接続を待ち、左側の状態が「接続済み」になったことを確認します。
3. 使用するページを開きます。デバイスカードには名前、シリアル番号の一部、APP バージョンが表示されます。完全な番号は設定画面で確認できます。

複数台接続時はデバイスカードをクリックして切り替えます。更新中は処理が終わるまで切り替えないでください。**BOOT モード**ではファームウェア更新で APP を復旧できます。リアルタイム測定には APP の正常動作が必要です。

<a id="dashboard"></a>
## ダッシュボードとリアルタイムグラフ

接続後、「ダッシュボード」で開始アイコンをクリックします。測定値とグラフが更新されます。

| チャンネル | 内容 |
| --- | --- |
| VBUS / IBUS / POWER | 電圧（V）、電流（A）、電力（W） |
| D+ / D− | USB データ線の電圧 |
| CC1 / CC2 | USB-C CC ピンの電圧 |

チャンネル名をクリックすると曲線を表示／非表示にできます。電圧・電流・電力の目盛りは別です。グラフ上にマウスを置くと測定値を確認でき、データがない位置は `--` と表示されます。

サンプリングレートは **1・10・50 SPS**、表示時間は **10・30・60・120 秒**です。停止アイコンで取得を一時停止し、再開できます。停止時間はグラフの経過時間に含まれません。クリアすると履歴と経過時間がリセットされます。一時停止中にクリアした場合は再度開始してください。

<a id="emarker"></a>
## E-Marker と検出履歴

指定された端子にケーブルを接続し、「E-Marker」で「読み取り」または「連続読み取り」を選択します。連続検出の前に、デバイス出力から他の受電機器をすべて取り外してください。同じボタンで連続検出を停止できます。

デバイスが報告したケーブル種別、定格電流、最高電圧、USB 速度、PD バージョン、TBT、EPR、長さ／遅延が表示されます。未報告または識別できない項目は「不明」です。E-Marker が検出されない場合はケーブルと接続方法を確認してください。VDO の生データは画像の下に表示されます。

正常に読み取った結果は現在のセッションの検出履歴に追加されます。エクスポートすると日時、ケーブル情報、VDO を含む `.xlsx` ファイルが作成されます。日時は UTC+8 です。終了すると履歴は消えるため、必要なデータは事前に保存してください。

<a id="protocol"></a>
## 充電プロトコルと PDO

指定端子に充電器または給電側を接続し、「PD 検出」で検出を開始します。検出中は電圧が上昇する場合があるため、開始前にデバイス出力から受電機器を取り外してください。同じボタンで検出を停止できます。

報告された PDO の電圧・電流・電力と、各項目の合格・失敗・待機・非対応などの状態を表示します。検出できる項目はデバイスのファームウェアによって異なります。デバイスが使用中の場合は、実行中の検出を停止してから操作してください。

<a id="firmware"></a>
## デバイスのファームウェア更新

このページは **USB-C Explorer 本体**のファームウェアを更新します。

1. デバイスを接続し、「アップグレード」画面を開きます。
2. 「バージョンを取得」をクリックして一覧を読み込みます。
3. 更新内容を確認し、ハードウェアに対応したバージョンを選びます。複数の BIN がある場合は説明に従って選択します。
4. 対象カードの「更新」をクリックします。選択したファームウェアをダウンロード・検証してからデバイスに転送します。進行状況と結果はカードに表示されます。

ダウンロードするのは選択したファイルのみで、処理後に一時ファイルを削除します。更新中は USB を接続したままにし、デバイスを切り替えないでください。完了後は設定画面でデバイス情報を更新し APP バージョンを確認します。失敗した場合はエラーを控え、接続と互換性を確認して再試行してください。

<a id="theme"></a>
## デバイスのテーマカラー

「テーマ設定」を開き、矢印でプレビューページを切り替え、編集可能な色をクリックします。プレビュー下の背景選択でも色を変更できます。「デバイスに適用」でプレビューし、「デバイスに保存」で再起動後も保持できます。

プレビューには測定、統計、E-Marker、プロトコル検出、デバイス設定があります。統計ページではタイトル、MAX、CUR、Ah、Wh の領域を設定できます。各領域の変更には対応するデバイスファームウェアが必要です。

| 操作 | 内容 |
| --- | --- |
| 初期値に戻す | プレビューの色を初期値に戻す |
| デバイスから読み取る | 現在のデバイス配色でプレビューを置き換える |
| デバイスに適用 | 保存せずにデバイスでプレビューする |
| デバイスに保存 | 適用して再起動後も保持する |

ボタンにマウスを合わせると説明が表示されます。一部の領域が変わらない場合はファームウェアの対応状況を確認してください。

<a id="settings"></a>
## 言語・外観・デバイス情報

「表示言語」で简体中文、English、Deutsch、日本語、Français を選択できます。選択は保存され、デバイス画面の言語は変更されません。ファームウェアの更新内容は公開者が用意した翻訳を使用し、デバイスの生データは原文のままです。

サイドバーのボタンで明暗テーマとサイドバーの表示を切り替えられます。パソコン側の外観とデバイスの配色は別々に設定します。設定画面にはモデル、ファームウェア、完全なシリアル番号、製造ロットが表示され、更新ボタンで再取得できます。問題の調査には動作ログを参照してください。

<a id="software-update"></a>
## UCE Tool の更新

これはデバイスではなく**パソコン上のアプリ**の更新です。Windows は画面上部の「このアプリについて → 更新を確認」、macOS はシステムメニューの「UCE → 更新を確認」を使用します。

対応する更新がある場合は画面の指示に従ってください。自動更新できない場合は、リリースページから対応するパッケージをダウンロードし、旧版を終了してから手動で置き換えます。デバイスのファームウェア処理中は終了まで待ってください。DMG 更新に未対応の旧 Mac 版は、最初に新版を一度手動インストールする必要があります。

<a id="faq"></a>
## よくある質問

- **接続できない：** データ対応ケーブルと USB ポートを確認し、他のシリアル通信ツールを閉じ、対応する APP ファームウェアを確認してください。OS が認識しているのに接続できない場合はログを確認します。
- **値やグラフが表示されない：** 接続を確認し、測定を開始してください。一時停止中や BOOT モードでは測定されません。
- **E-Marker が「不明」：** ケーブルやファームウェアがその情報を返していない可能性があります。VDO 生データなどを確認してください。
- **GitHub へのアクセス失敗・制限：** ネットワークやプロキシを確認し、時間を置くか別のネットワークで再試行してください。エラー全文を控えてください。旧 Mac 版で証明書エラーが出る場合は修正済みの新版を手動インストールしてください。
- **配色がデバイスに反映されない：** 接続後「適用」または「保存」を実行し、対象領域に対応するファームウェアを確認してください。再起動後も保持するには「保存」を使用します。
- **Mac の選び方：** Apple Silicon は `arm64`、Intel は `x86_64` です。「この Mac について」で確認できます。
- **アプリを自動更新できない：** リリースページから対応するパッケージを入手し、旧版を終了して手動で置き換えてください。

問題を報告する際は、OS とプロセッサ、UCE Tool のバージョン、デバイスのハードウェアと APP のバージョン、操作手順、エラー全文または画面画像、関連するログをお知らせください。
