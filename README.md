# UCE Tool

**简体中文** | [English](README.en.md) | [Deutsch](README.de.md) | [日本語](README.ja.md) | [Français](README.fr.md)

UCE Tool 是 USB-C Explorer 的电脑端配套工具，用于查看实时测量数据、读取 E-Marker、检测充电协议、更新设备固件和配置设备主题颜色。

支持 **Windows 64 位、Mac M 系列和 Mac Intel**，界面提供 **简体中文、English、Deutsch、日本語、Français** 五种语言。

## 下载与安装

### 选择下载文件

进入 [Releases 发布页](https://github.com/Tamako-zz/UCE-Tool/releases/latest)，展开 **Assets**，根据电脑类型选择：

| 文件 | 适用电脑 | 解压后的程序 |
| --- | --- | --- |
| `UCE-Windows-x64.zip` | Windows 64 位，Intel / AMD 处理器 | `UCE.exe` |
| `UCE-mac-arm64.dmg` | Mac，Apple Silicon（M 系列）处理器 | `UCE.app` |
| `UCE-mac-x86_64.dmg` | Mac，Intel 处理器 | `UCE.app` |

普通使用请选择上面的应用包。

Mac 用户可以在苹果菜单的“关于本机”中查看处理器：显示 Apple 芯片或 M 系列型号时，选择 `arm64`；显示 Intel 时，选择 `x86_64`。

### Windows

1. 下载 `UCE-Windows-x64.zip`。
2. 先完整解压到电脑上的文件夹。
3. 双击解压后的 `UCE.exe` 启动。

建议从解压后的文件夹运行程序，便于后续更新和替换文件。

### macOS

1. 下载与处理器匹配的 Mac dmg。
2. 打开 DMG，将 `UCE.app` 拖入 `Applications`（应用程序）文件夹。
3. 退出磁盘映像，从“应用程序”文件夹打开 UCE。
4. 首次打开如被系统拦截，请确认应用来自本项目，再到“系统设置 → 隐私与安全”中允许打开。

## 第一次连接设备

### 准备

- USB-C Explorer 设备。
- 一根支持数据传输的 USB 线。
- 与设备硬件配套的 APP 固件；主题和协议检测等功能还需要相应的固件支持。

### 连接步骤

1. 启动 UCE Tool。
2. 通过设备的数据通信接口将设备连接到电脑。
3. 软件会扫描设备并尝试自动连接。
4. 查看左侧设备卡片，确认状态变为 **“已连接”**。
5. 打开所需功能页，例如“仪表盘”或“E-Marker”。

左侧卡片会显示设备名称、序列号和 APP 固件版本。卡片中的序列号可能只显示末尾部分，完整序列号可在设置页的“设备信息”中查看。

连接多台设备时，可以点击左侧对应的设备卡片进行切换。升级期间请等待任务结束后再切换设备。

设备处于 **BOOT 模式**时，可以使用固件升级流程恢复 APP；实时测量等功能需要设备正常运行 APP 固件。

## 仪表盘与实时曲线

### 开始测量

1. 确认设备已连接。
2. 进入“仪表盘”。
3. 点击曲线区域的 **开始图标 ▶**。
4. 顶部数值和下方曲线会随设备数据更新。

| 项目 | 含义 |
| --- | --- |
| VBUS | 电压，单位 V |
| IBUS | 电流，单位 A |
| POWER | 功率，单位 W |
| D+ / D− | USB 数据线电压 |
| CC1 / CC2 | USB-C CC 引脚电压 |

### 选择曲线

点击曲线上方的通道标签，可以显示或隐藏对应曲线。电压、电流、功率使用各自的刻度，查看数值时请同时确认单位。

将鼠标移到曲线区域，可以查看对应时间附近的采样数值。没有采样数据的位置会显示 `--`。

### 采样率与显示时长

| 设置 | 可选值 | 作用 |
| --- | --- | --- |
| 采样率 | 1、10、50 SPS | 控制每秒请求的采样次数 |
| 显示时长 | 10、30、60、120 秒 | 控制曲线可视的时间范围 |

例如，50 SPS 表示每秒 50 次采样。显示时长改变的是查看范围，采样率改变的是采集频率。

### 暂停与清空

- **暂停**：点击停止图标后，实时数值和曲线暂时保持不变；再次开始后继续采集。
- **计时规则**：暂停时长不计入曲线时间。例如在 25 秒暂停，等待 1 分钟后恢复，曲线仍从约 25 秒继续。
- **清空**：点击清空图标，删除当前曲线历史，下一次采样从 0 秒开始计时。暂停期间清空后，仍需点击开始才能继续采集。

## 读取 E-Marker 与导出记录

### 查看线缆信息

1. 按设备接口标识接入待测线缆。
2. 在 UCE Tool 中进入“E-Marker”。
3. 点击 **“读取”**，或点击 **“连续查询”** 开始连续检测。
4. 在“线缆信息”标签下查看设备返回的结果。

根据线缆与固件提供的信息，页面可显示线缆类型、额定电流、最高电压、USB 数据传输能力、PD 协议版本、Thunderbolt / TBT、EPR 和长度／延迟信息。

设备未上报或当前无法识别的项目会显示“未知”。显示“未发现 E-Marker”时，请结合线缆是否带有 E-Marker、接入方式及设备连接状态检查。

页面下方的 **“E-Marker 原始数据”** 用于查看设备返回的 VDO 等数据。

### 查看与导出检测记录

每次成功读取到有效 E-Marker 信息后，软件会将结果加入本次运行的检测记录。

1. 点击 **“检测记录”** 查看列表。
2. 点击导出图标，选择保存位置。
3. 软件会生成 **`.xlsx` Excel 文件**，包含检测时间、线缆信息及原始 VDO 等内容。

记录时间使用北京时间（UTC+8）。记录保存在本次软件运行期间，退出前请导出需要保留的数据；点击清空记录后会移除当前列表。

<a id="protocol"></a>

## 充电协议与 PDO 检测

1. 按设备接口标识接入待测充电头或供电端。
2. 进入 **“PD检测”** 页面。
3. 点击 **“开始检测”**。
4. 等待设备返回协议、PDO 及各项检测状态。
5. 如需中止，点击 **“停止检测”**，等待设备结束当前检测。

页面会根据设备上报的信息展示电压、电流、功率等 PDO 参数，以及通过、失败、待检测或不支持检测等状态。可检测的项目由设备固件决定。

如果提示设备忙，请先停止当前检测，再进行固件升级、主题操作或其他设备操作。

## 升级设备固件

“升级”页面更新的是 **USB-C Explorer 设备内的固件**。

### 操作步骤

1. 保持设备与电脑连接。
2. 进入 **“升级”** 页面。
3. 点击 **“获取版本”**，等待软件获取版本列表。
4. 查看版本卡片中的版本号、日期及更新内容。内容较长时，可以在卡片内部滚动。
5. 选择与设备硬件匹配的版本。
6. 点击对应卡片中的 **“更新”**，下载并校验后开始升级。
7. 在版本卡片中查看下载状态和升级百分比，等待完成提示。

获取版本时不会下载固件。点击“更新”后只下载所选固件，升级结束后清理本次临时文件。同一版本如果包含多个固件包，请结合发布说明选择对应硬件的包。

### 升级过程

- 升级期间保持 USB 连接，等待任务结束后再操作或切换设备。
- 软件会检查固件包，并在适用的设备固件上尝试准备升级。
- 如果提示需要进入 Bootloader，请按照设备配套固件的说明进入升级模式后重试。
- 完成后可到设置页点击 **“刷新设备”**，确认 APP 固件版本。

如果升级失败，请保留提示内容，检查 USB 连接、固件与硬件是否匹配，再重新获取固件并重试。

<a id="theme"></a>

## 配置设备主题颜色

### 编辑配色

1. 进入 **“主题配置”** 页面。
2. 使用左右箭头切换设备页面预览。
3. 点击预览中的可编辑色块，选择颜色并确认。
4. 通过预览下方的背景选择器修改该页背景色。
5. 点击“应用到设备”预览实际效果，满意后点击“保存到设备”。

预览包括实时测量、统计、E-Marker、协议检测和设备设置五个页面。统计页用色块表示标题、MAX、CUR、Ah、Wh 的可配置区域。

### 四个按钮的作用

| 按钮 | 作用 |
| --- | --- |
| 恢复默认 | 将所有预览页的配色恢复为默认值；之后可以应用或保存到设备 |
| 从设备读取 | 读取设备当前配色，覆盖当前编辑中的预览配色 |
| 应用到设备 | 立即更新设备配色，用于预览；配色尚未永久保存 |
| 保存到设备 | 将当前配色应用并保存，断电重启后仍保留 |

四个按钮在预览图下方横向排列，鼠标停留在按钮上时，下方会显示简短说明。

统计页的新色块需要配套的设备固件映射支持。如果上位机预览已变化、设备对应区域没有变化，请确认设备也已升级到支持这些区域的固件。

## 语言、外观和设备信息

### 界面语言

打开设置页，在 **“界面语言 / Interface Language”** 中选择：

- 简体中文
- English
- Deutsch
- 日本語
- Français

选择会自动保存，下次启动继续使用。此设置影响电脑端界面；设备屏幕内容由设备固件决定。固件发布说明使用发布者提供的翻译，设备原始数据保留原文。

### 明暗外观与侧边栏

- 点击左侧的明暗切换图标，更换电脑端界面外观。
- 点击侧边栏图标，可以收起或展开左侧导航。
- 右侧页面内容可以独立滚动，左侧导航保持可用。

电脑端的明暗外观与“主题配置”里的设备配色分别设置。

### 设备信息与运行日志

设置页的“设备信息”会显示型号、固件版本、完整序列号和批号。点击标题旁的 **“刷新设备”** 可以重新读取，信息文字可选中复制。

连接、检测和升级出现问题时，可以查看同页的运行日志，并在反馈问题时提供相关内容。

## 更新 UCE Tool 软件

软件更新用于更新 **电脑上的 UCE Tool 应用**。

| 平台 | 检查更新的位置 |
| --- | --- |
| Windows | 窗口顶部的“关于”图标菜单 → 检查更新 |
| macOS | 屏幕顶部的 UCE 菜单 → 检查更新 |

检查完成后，弹窗会显示版本提示。完整版本说明可点击 **“前往发布页”** 查看。

- 有可用且匹配的更新包时，可以按弹窗提示更新。
- 如果“更新”不可用，请到发布页手动下载对应系统和架构的应用包。
- 手动更换应用前，先退出旧版程序。
- 设备固件任务运行期间，请等待任务结束后再更新上位机软件。

## 常见问题

### 设备一直显示“未连接”

先确认 USB 线支持数据传输，并尝试更换 USB 端口。关闭可能占用串口的串口终端、调试或烧录工具，再重新连接设备。

如果系统本身没有识别到设备，请先检查设备连接与运行状态；如果系统已经识别到设备但软件仍无法连接，请查看运行日志，并确认设备使用配套的 APP 固件。

### 仪表盘显示 `--`，没有曲线

确认左侧为“已连接”，再点击仪表盘的开始图标。处于暂停状态、BOOT 模式或尚未收到采样数据时，曲线不会继续更新。

### E-Marker 某些项目显示“未知”

当前线缆或设备回复可能未提供对应字段，也可能尚未提供可识别的扩展信息。可以结合原始 VDO、其他检测项和设备固件版本判断。

### 获取版本时网络请求失败或请求受限

版本获取和固件下载需要访问 GitHub。请检查网络与代理设置，也可以尝试切换网络后重试。浏览器能访问网页时，软件使用的接口请求仍可能受代理、证书或请求额度影响。

反馈时请保留完整错误提示。如果使用旧版 Mac 应用遇到证书验证错误，请先更换为包含证书修复的新版应用，再测试。

### 主题颜色预览变化了，设备没有变化

确认已经连接设备，并点击了“应用到设备”或“保存到设备”。只在颜色选择器中确认颜色，会先更新电脑端预览。

如果只有特定区域没有变化，请检查设备固件是否支持该区域的改色。

### 重启设备后，配色恢复了

使用“保存到设备”保存配色。“应用到设备”用于即时预览，未永久保存的颜色不会在重启后保留。

### Mac 应该下载哪个版本

Apple Silicon（M 系列）选择 `arm64`，Intel 选择 `x86_64`。可以通过苹果菜单中的“关于本机”查看处理器类型。

### 软件提示发现新版本，但不能直接更新

可能没有匹配当前系统或架构的附件，或当前安装位置不适合自动替换。请点击“前往发布页”，下载匹配的应用包，退出旧版后手动替换。

### 怎样反馈问题

请尽量提供：

- Windows / macOS 版本，以及 Intel、AMD 或 Apple Silicon 处理器类型。
- UCE Tool 软件版本。
- 设备硬件版本和 APP 固件版本。
- 操作步骤、完整错误提示或截图。
- 与问题相关的运行日志。
